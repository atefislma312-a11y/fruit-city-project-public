# فحص وتسليم Fruit Archives — China 1968

الحالة: معاينة تصميم للمراجعة، وليست نسخة مصرحًا بنشرها نهائيًا.

- فُتح المرفقان الأصليان من مرفقات المحادثة. ZIP يحتوي README و14 طبقة PNG شفافة، جميعها 1440×2560. ملف ORA المذكور في README غير موجود؛ أُنشئ ملف ORA جديد من الطبقات.
- حُفظت طبقة الكوب الأصلية دون إعادة رسم أو تلوين. اختبار المنطقة المعتمة داخل الشعار: صفر بكسل مختلف.
- لا توجد صور تاريخية مولدة في هذا التسليم. الخلفية تركيب من طبقات الملف المرفوع؛ لم يُثبت أصل كل بكسل فيها بصورة مستقلة.
- استُبدلت بطاقة القصة بنص مختصر يدعمه متحف Cooper Hewitt، وحُذفت عبارة أن أحدًا في شمال الصين لم ير مانجا. استُخدم أغسطس 1968 بدل يوم محدد غير مثبت بالمصدر المتحقق منه.
- SVG يحفظ الصور المضمنة والنصوص القابلة للتعديل. HTML يغير البلد والسنة والحدث والتاريخ والقصة ويصدر SVG. الصور نفسها تتغير يدويًا في ملف الطبقات؛ لا توجد آلية بحث صور تلقائية. تمت مراجعة PNG بصريًا؛ محرر HTML لم يُختبر تفاعليًا.

## النواقص والتصحيحات

1. صورة أرشيفية موثقة للحدث نفسه (تسليم المانجا أو عرضها) غير موجودة بالمرفقات. هذا لا يثبت عدم وجود صور حرة في أي مكان.
2. رابط القطعة التذكارية هو قصّة بورتريه ماو فقط، وليس صورة للقطعة كاملة أو لحظة الحدث. أبقي مع تسمية صريحة.
3. صفحة صورة الحرس الأحمر 1966 عليها ترشيح للحذف منذ 22 يوليو 2026؛ يلزم حسم حقوقها أو استبدالها قبل النشر. لم نفترض سبب الترشيح.
4. لم ينجح فتح صفحة خريطة الصين للتحقق، ولا توجد ملفات أصلية أو سجل تحويل يربط كل طبقة بالمصدر. يلزم تثبيت مصدر الخريطة والخشب وبقية الأصول.
5. تاريخ صورة المانجا في المصادر المرفوعة خاطئ: الصفحة الحالية تقول 27 يناير 2022، المصور Ivar Leidus، CC BY-SA 4.0. نُسبت الصورة في المعاينة؛ شروط المشاركة بالمثل يجب مراعاتها عند حسم النشر. الفاكهة في الصورة ليست دليلًا على صنف زبدة.
6. صورة الكوب الخام السابقة للاقتصاص غير موجودة في ZIP؛ المتاح طبقة مقصوصة ذات حواف غير مثالية. احتُفظ بها كما هي احترامًا للشعار.
