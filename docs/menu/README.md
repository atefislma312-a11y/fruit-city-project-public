## 🔄 5. سياسة الرمز الموحد للأصناف المشتركة (Shared Items & Unified SKU)
لمنع الازدواجية في المخزون أو إرباك الكاشير، تم اعتماد كود **Garden Fusion (`GF`)** ككود رئيسي (Master SKU) للأصناف المشتركة:
* **إيه بي سي (ABC):** كود `GF01` (مشترك مع `C01`).
* **روبي بيت (Ruby Beet):** كود `GF04` (مشترك مع `C02`).
* **جرين جاردن (Green Garden):** كود `GF05` (مشترك مع `D04`).
* **سيتروس روبي (Citrus Ruby):** كود `GF06` (مشترك مع `C03` و `E08`).

## 📋 6. هيكل البيانات المطلوب لكل صنف (Item Schema)

| الحقل (Field) | الرمز البرمجي | النوع | الوصف والاشتراطات |
| :--- | :--- | :--- | :--- |
| **كود الصنف** | `item_code` | String (Unique) | كود تعريفي فريد في القائمة (مثال: `PJ01`, `C01`) |
| **الرمز الموحد** | `unified_code` | String | الرمز المعتمد في المخزون ونقاط البيع (مثال: `GF01` لـ `C01`) |
| **اسم الصنف** | `item_name` | Object | الاسم باللغتين العربية والإنجليزية (`ar` / `en`) |
| **القسم / التصنيف** | `category_name` | Object | اسم القسم بالعربي والإنجليزي |
| **المجموعة الفرعية**| `subgroup` | String / Null | المجموعة الفرعية (A, B, C, D, E في قسم النشاط) |
| **الأحجام المتاحة** | `available_sizes`| Object | مصفوفة الأحجام (كوب 16 أونص، إزازة 500 مل، إزازة 1 لتر) مع حقل السعر |
| **المكونات** | `ingredients` | Array / List | قائمة دقيقة بجميع المكونات (فواكه، خضار، إضافات) |
| **حالة الاعتماد** | `status` | String | القيمة الثابتة: `معتمد` |
