# تسليم صور وقصص المنيو إلى Antigravity

أضف المنيو كوجهة إضافية للشغل الحالي في التسويق والسوشيال ميديا والمبيعات. المطلوب نقل الصورة والمحتوى اللذين اعتمدهما إسلام، وتجربة منتج واحد أولًا. تصميم الزر وعرض القصة جاهز لدى Codex؛ لا تعِد تصميمه ولا تنشئ صورًا أو محتوى جديدًا لهذه المهمة.

المشروع: `D:\fruit city project\web_app\app_code`.

- ضع نسخة الصورة المعتمدة في `public/stories/` باسم إنجليزي، مثل `PJ01.webp` (يدعم أيضًا jpg وpng). حافظ على الأصل.
- أضف سجل المنتج إلى `src/product-stories.json` باستخدام SKU الأصلي نفسه. لا تستبدل بقية السجلات.
- `approved: false` يبقي القصة مخفية. غيّرها إلى `true` فقط بعد تأكيد إسلام للصورة والمحتوى. هذا علم محتوى في الملف، وليس لوحة موافقات أو صلاحية نشر.
- يظهر زر «اعرف القصة» تلقائيًا أسفل يمين صورة المنتج عند اكتمال السجل واعتماده، ويفتح صورة وعنوانًا وفقرات وزر طلب متصل باختيار الحجم الحالي. الصورة نفسها تظهر في بطاقة المنتج.

قالب هيكلي فقط؛ استبدل النصوص بالمحتوى المعتمد:

```json
{
  "PJ01": {
    "sku": "PJ01",
    "approved": false,
    "image": "/stories/PJ01.webp",
    "title": "العنوان المعتمد",
    "paragraphs": ["الفقرة الأولى المعتمدة", "الفقرة الثانية المعتمدة"]
  }
}
```

استخدم نصًا عاديًا، لا HTML. لا تغير الأسعار أو أكواد المنتجات أو السلة. اختبر `npm test` و`npm run build` من مجلد التطبيق، ثم افحص الصورة والقصة في المتصفح قبل التسليم. رفع GitHub أو نشر النسخة العامة يتطلب أمرًا مستقلًا من المالك.

معاينة التصميم المحلية فقط: شغّل `npm run dev` وافتح `http://127.0.0.1:5174/?storyPreview=1#product-story/PJ01`. تستخدم صورة المنيو الموجودة ونصًا توضيحيًا، ولا تدخل المعاينة في بناء الإنتاج. لا توجد حاليًا قصة معتمدة في ملف البيانات. لم تُنشأ لوحة موافقات في هذه المهمة.

## المحتوى ثنائي اللغة — 2026-10-27
الصور تبقى كما هي بطلب المالك. أضف لكل قصة كائن `en` بجانب `title` و`paragraphs` العربيين: `"en": {"title":"English title","paragraphs":["English paragraph"]}`. تمت ترجمة قصة PJ01 الموجودة؛ هذا نقل لغوي للنص وليس تدقيقًا مستقلًا لمعلوماته التاريخية. أي قصة لاحقة بدون ترجمة سليمة تظهر لها رسالة انتظار بالإنجليزية بدل تسريب النص العربي. لا تغيّر ملف الصورة لتبديل اللغة. زر English / AR يبدّل النصوص واتجاه العرض ويحفظ الاختيار محليًا. مدخلات العميل الحرة لا تُترجم تلقائيًا. نموذج Checkout وصندوق StaffInbox التجريبيان خلف VITE_INTAKE_DEV ليسا ضمن ترجمة واجهة WhatsApp العامة الحالية.
