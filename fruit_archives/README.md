# Fruit City — أرشيف الفواكه v0.1

استوديو محلي عملي لإنتاج ومراجعة حزم الحلقات، مستقل عن الطلبات والكاشير. لا مفاتيح API ولا خدمات مدفوعة ولا نشر تلقائي.

## التشغيل

من PowerShell داخل `D:\fruit city project`:

```powershell
node fruit_archives/server.mjs
```

افتح http://127.0.0.1:5186 . يستخدم Node 22 أو أحدث، دون تثبيت حزم. الحلقة المرجعية موجودة؛ **لا تعيد seed** فوقها. `seed.mjs` مخصص للتأسيس مرة واحدة ويرفض الاستبدال.

## إضافة حلقة

1. اختر صنفًا موجودًا في منيو `docs/menu/menu_items.json` (108 إدخالات، منها مشروبات ومكسات؛ ليست كلها فواكه منفردة). لا أسعار مستوردة ولا مخترعة.
2. اكتب معرفًا إنجليزيًا مستقلًا مثل `guava-event-01` واسم الحدث والبلد والسنة. نفس الفاكهة تقبل أحداثًا متعددة بمعرفات مختلفة.
3. اكتب القصة بعد البحث. المسودة الجديدة تنشئ حقول المنصات والهوكات التمهيدية، **لا تولّد بحثًا تاريخيًا أو نصوصًا نهائية آليًا**.
4. أضف المصادر والادعاءات والمشاهد والحقوق من محرر JSON المتقدم. النسخة الأولى لا توفر نماذج مستقلة سهلة لكل هذه الحقول؛ تظهر صفحة مراجعة مقروءة بعد الحفظ.
5. حرر كل كابشن بشكل مستقل، واختر الهوكات والألوان. `A` يستخدم هوك المنصة؛ `B` يستخدم البديل العام. تغيير اختيار الهوك العام لا يستبدل هوكات المنصات تلقائيًا.
6. «حفظ نسخة» يحفظ `episode.json` ونسخة سابقة داخل `versions/`؛ يتصدى للتعديلات القديمة من نافذة أخرى. لا تستعمل عمليتي خادم على نفس مجلد الحلقات.
7. «حفظ صورة مسودة» يحفظ المقاس المحدد. «تصدير كل المقاسات A/B» يحفظ 42 صورة (7 مقاسات/منصات × A/B × PNG/JPG/WebP). نسخ الريلز أغلفة ثابتة وليست فيديو.
8. «تصدير حزمة المسودة» يكتب مجلدًا مستقلًا تحت `episodes/<id>/exports/draft-v…` يشمل البيانات والنصوص والأصول وملفات التصدير المتوفرة والقالب البرمجي. لا ZIP وهمي ولا إرسال خارجي.

## الحدود الحالية

- **الكوباية للمراجعة فقط** بقرار المالك في 2026-10-25؛ لم يؤكد MASTER CUP V1 أو حقوقها التجارية. لا اعتماد نشر.
- التصميم الجديد معاينة تخطيطية متغيرة الألوان بالنص العربي وصورة الكوباية؛ لا يحقق بعد المعالجة السينمائية الكاملة للتصميم المرجعي. المرجع محفوظ كصورة ومرتبط بأصل ORA/SVG القائم دون تغيير.
- خلفيات التصميم السابق لها نواقص حقوق وأصل تاريخي. لا تستخدم في صادرات القالب الجديد. لا يوجد إثبات لصورة أصلية لتسليم المانجا.
- الاعتماد النهائي معطّل صراحة في v0.1 حتى مع تحرير JSON؛ زر الفحص يعرض العوائق ولا يدعي الاعتماد. لا مصادقة مستخدمين/فريق؛ هذه أداة على loopback فقط.
- التحقق من الروابط في الإدخال يتحقق من الصيغة والبروتوكول؛ المصادر المرجعية راجعت يدويًا بالويب لهذه الحلقة. لا crawler ولا إعادة تحقق آلية من صحة المصدر أو جودة محتواه.
- إنتاج الفيديو والتعليق الصوتي والموسيقى والكاروسيل المصور الكامل غير منفذ؛ النصوص والمشاهد والشرائح موجودة كبيانات.
- تسجيل الأداء يدوي في `performance` عبر JSON (platform, variant, impressions, clicks, saves, date). لا اتصال بإحصاءات المنصات.
- المقال HTML محلي للمراجعة؛ لا إدماج أو نشر في المتجر. canonical URL فارغ عمدًا؛ ربط قسم المنيو/حلقات منشورة يتطلب مسار نشر معتمد.
- لا رفع ملفات من المتصفح. أضف صورة آمنة يدويًا داخل `assets/` وسجّل مصدرها وترخيصها وSHA-256؛ النظام يقبل PNG/JPG/WebP بمسار محصور.
- الحفظ مصمم لخادم واحد على جهاز واحد، وليس خدمة إنترنت متعددة المستخدمين. يجب حفظ نسخة احتياطية للمجلد قبل الاستخدام التشغيلي المكثف.

## ملفات النظام

- `core.mjs`: نموذج الكيانات، التحقق، النسخ، الحزم.
- `server.mjs`: خادم محلي محدود المسارات وOrigin/Host وحجم المدخلات، وكتابة الصور.
- `public/`: واجهة RTL وقالب Canvas بكتابة عربية أصلية من المتصفح.
- `templates/episode-template.json`: متغيرات قالب عام.
- `episodes/mango-china-1968/`: البحث والادعاءات والمقال ونصوص المنصات والمشاهد ونتائج التصدير.
- `audit/`: جرد الملفات وحدود فحصها، وتقرير الموجود والناقص.
- `tests/`: اختبارات منيو ونسخ وحزم وHTTP ورفض الاعتماد والمدخلات غير الآمنة.

```powershell
node --test fruit_archives/tests/*.test.mjs
node fruit_archives/audit.mjs
```

مقاسات القالب خيارات إنتاج للمشروع وليست قائمة حية بكل مواصفات الإعلانات. النص العربي يستخدم Tahoma/Arial المتاحين على ويندوز؛ تغير الجهاز/الخط قد يغير التفاف السطور. كل صورة تحمل علامة «مسودة للمراجعة فقط».
